# Career Guidance and Recommendation System

Welcome to the **Career Guidance and Recommendation System**! This project is designed to help students and job seekers discover regional scholarships, internships, and local career opportunities tailored to their skills, education, and preferences. The system leverages **NLP (Natural Language Processing)** to provide an intuitive and interactive experience.

---

## Features

### 1. **Career Portal Aggregation with NLP Integration**
- Aggregates job postings, internships, and scholarships from multiple sources.
- Allows users to interact with the platform using natural language queries (e.g., "Show me data science internships in Bangalore for freshers").
- Provides personalized recommendations based on user profiles (skills, education, location).

### 2. **Learning Path Advisor**
- Identifies skill gaps in a user’s profile.
- Recommends personalized learning paths, including online courses, tutorials, and certifications.
- Tracks user progress and provides dynamic updates based on emerging trends.

### 3. **AI-Powered Resume Analyzer**
- Analyzes resumes to extract skills, education, and experience.
- Recommends job opportunities tailored to the user’s profile.
- Suggests courses and certifications to improve missing skills.
- Sends periodic updates about new job postings and learning resources.

---

## Tech Stack

- **NLP**: [SpaCy](https://spacy.io/) for text processing, entity extraction, and resume parsing.
- **Frontend**: [Streamlit](https://streamlit.io/) for building an interactive web interface.
- **Backend**: Python for data processing, recommendation logic, and integration with APIs.
- **Database**: SQLite (or any lightweight database) for storing user profiles and opportunity data.
- **APIs**: Integration with job boards, scholarship portals, and course platforms (e.g., Coursera, Udemy).

---

## How It Works

1. **Career Portal Aggregation**:
   - The system scrapes and aggregates data from multiple sources (e.g., Naukri, Internshala, LinkedIn).
   - Users interact with the platform using natural language queries.
   - The system uses NLP to understand user profiles and recommend tailored opportunities.

2. **Learning Path Advisor**:
   - Users input their career goals and current skills.
   - The system identifies skill gaps and recommends learning resources.
   - Users can track their progress and receive updates on new courses.

3. **AI-Powered Resume Analyzer**:
   - Users upload their resumes.
   - The system extracts key details (skills, education, experience) and recommends jobs and courses.
   - Users receive periodic updates about new opportunities and learning resources.

## Setup Instructions

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)

### Libraries Used
 - Streamlit: For building the interactive web interface.
 - SpaCy: For NLP tasks like text processing, entity extraction, and resume parsing.
 - Pandas: For data manipulation and analysis.
 - NumPy: For numerical computations.
 - Requests: For making HTTP requests to fetch data from APIs or websites.
 - BeautifulSoup4: For web scraping job postings and scholarships.
